# 论文复现数据与主代码

对应论文：Risk-Aware Neuro-Symbolic Quality Function Deployment and Resource-Constrained Engineering Characteristic Improvement Based on Online Reviews。

本仓库整理了双品牌全量 QFD 应用分析的冻结输入、主分析代码和数据字段说明。数据包含 14,825 条原始评论及 525,647 条评论语义片段，覆盖蔚来和比亚迪。

## 文件说明

- `数据/01_评论片段与冻结评分/双品牌评论语义切片原始记录.xlsx`：双品牌合并后的清洗和切片记录。
- `数据/01_评论片段与冻结评分/双品牌评论片段_全量情感效价与工程严重度冻结评分.csv`：全量语义片段及冻结情感和严重度模型输出。
- `数据/01_评论片段与冻结评分/数据字典_评分CSV字段说明.md`：评分 CSV 的 28 个字段及严重度等级解释。
- `数据/02_BGE-M3语义特征/shards/`：106 个与评分数据行对齐的 BGE-M3 特征分片，包含 dense/sparse 特征和行对齐信息。
- `数据/03_工程知识图谱/冻结工程特性本体与符号约束图谱.xlsx`：32 个二级工程特性、一级技术域和符号规则。
- `数据/04_候选方案与评审/`：历史工程候选方案及独立评审记录。
- `数据/05_外部验证/`：车质网与懂车帝的蔚来外部验证排序数据。
- `数据/06_模型比较指标/`：情感模型和工程严重度模型的汇总指标。
- `数据与代码清单_SHA256.csv`：逐文件大小和 SHA256 校验值。
- `主代码/`：评分接口转换、神经符号映射、风险聚合、拓扑传播、Bootstrap、候选方案/MILP、敏感性和外部验证主程序。

## 复现范围

分析从已冻结的全量情感效价/严重度评分及 BGE-M3 特征开始，重新运行 QFD 映射和后续定量分析。情感和严重度模型的重新训练代码、人工标注训练集及模型权重不在本仓库中。模型汇总指标和全量冻结评分已提供。

## 运行

需要 Python 3.10 或更新版本，以及 pandas、numpy、scipy、scikit-learn、pyarrow、openpyxl、networkx 等依赖。在仓库根目录运行：

    python 主代码/主程序_按论文流程顺序运行.py

生成的分析结果保存在各阶段目录中；.gitignore 已排除这些派生输出。

## 大文件

大 CSV、Excel 工作簿和 BGE-M3 特征通过 Git LFS 跟踪。克隆和下载完整数据需要安装 Git LFS。
