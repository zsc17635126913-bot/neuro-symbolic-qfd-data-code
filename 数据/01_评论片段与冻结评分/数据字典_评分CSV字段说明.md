# 全量评论片段与冻结评分 CSV：字段说明

文件：双品牌评论片段_全量情感效价与工程严重度冻结评分.csv

每一行是一条评论语义片段，不是一条完整原始评论。同一条原始评论可能切分成多行，可用“原始评论分组ID”找回同组片段。

## 来源与索引字段

| 列名 | 含义 |
|---|---|
| 打分原始行号 | 评分程序生成的顺序号，从 0 开始。 |
| 打分使用文本列 | 评分模型实际使用的文本字段名；本实验优先使用 Filtered_SubSeq。这是字段名标记，不是评论内容。 |
| 片段行号 | 合并后的语义切片表中，为片段分配的全局序号。 |
| 品牌 | 评论所属品牌：蔚来或比亚迪。 |
| record_id | 单条原始评论文本记录的标识。 |
| 原始评论分组ID | 原始评论级分组标识；同一评论拆出的字段或片段可共享此 ID。 |
| source_file | 原始数据文件名。 |
| source_row_0基 | 原始来源表中的行位置，按 Python 习惯从 0 开始计数。 |
| field_name | 原始数据中评论文本所在的字段名。 |

## 评论文本和语义标签

| 列名 | 含义 |
|---|---|
| clean_text | 清洗后的原始评论文本；同一评论有多个片段时可能重复。 |
| Filtered_SubSeq | 切分后的语义片段文本，是情感、严重度和 BGE-M3 分析主要使用的文本。 |
| Entity | 片段中涉及的对象或工程实体。 |
| Aspect | 片段谈到的具体属性、功能或体验方面。 |

Entity 和 Aspect 是切片数据携带的语义信息，不是情感/严重度模型的预测列。

## 情感预测字段

| 列名 | 含义 |
|---|---|
| 预测情感类别 | 模型预测类别：负向、中性或正向。 |
| P_情感_负向 | 模型判定为负向的概率。 |
| P_情感_中性 | 模型判定为中性的概率。 |
| P_情感_正向 | 模型判定为正向的概率。 |
| 预测情感效价 | 连续情感效价，范围约为 -1 至 1；越低越偏负向。 |

三个 P_情感 字段是类别概率，通常合计约为 1。

## 工程后果严重度字段

严重度指评论表达的感知工程后果，不等于客观故障率、事故率或发生概率。

| 列名 | 含义 |
|---|---|
| 预测严重度_0到4 | 有序分类模型给出的等级 0–4。 |
| P_严重度0 | 预测为等级 0 的概率。 |
| P_严重度1 | 预测为等级 1 的概率。 |
| P_严重度2 | 预测为等级 2 的概率。 |
| P_严重度3 | 预测为等级 3 的概率。 |
| P_严重度4 | 预测为等级 4 的概率。 |
| P_严重度大于0 | 等级高于 0（等级 1–4）的累计概率。 |
| P_严重度大于1 | 等级高于 1（等级 2–4）的累计概率。 |
| P_严重度大于2 | 等级高于 2（等级 3–4）的累计概率。 |
| P_严重度大于3 | 等级高于 3（即等级 4）的累计概率。 |

等级含义：0 为不影响功能的轻微不满；1 为局部体验下降、主要功能正常；2 为便利性或可靠性感受明显受影响；3 为核心功能受阻、反复维修或出现明显风险；4 为严重安全疑虑或关键功能失效。P_严重度0 至 P_严重度4 是各等级概率；P_严重度大于0 至 P_严重度大于3 是彼此重叠的累计概率，不应相加。
